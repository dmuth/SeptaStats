
# SEPTA Stats

This used to be the website for SEPTA Stats, a project which pulled down SEPTA Regional Rail train data.

I sunsetted the site on May 13th, 2026 because it wasn't getting much use anymore and the technical complexity of the site just made it not worth running any longer.

All of the source code is at <https://github.com/dmuth/SeptaStats> if you'd like to give a shot standing up the software.  Note that the Slim framework for this site will desperately need to be updated.
